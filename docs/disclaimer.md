# 风险声明与免责

## 一、项目定位

本仓库为**安全防御、审计与检测方向**的个人开源项目，仅用于：

- AI Agent 权限边界的**只读审计**与评估；
- 最小权限原则（Least Privilege）的基线检查与整改留痕；
- 个人安全学习、合规检测与开源社区贡献。

本项目**不包含**任何攻击、爆破、漏洞利用、提权绕过或系统破坏能力，也不提供此类内容的实现细节。

## 二、工具行为边界（安全契约）

1. **只读**：探测脚本不修改系统状态；唯一写入为报告目录与一枚即建即删的临时文件。
2. **不读取秘密**：环境变量值、私钥、令牌、凭据文件内容一律不读、不输出。
3. **不提权**：不使用 sudo 执行任何命令；`sudo` 仅以 `-n -l` 查询权限状态，绝不弹窗、不执行。
4. **不发送载荷**：网络检查仅为 TCP 连接尝试与 DNS 解析，无数据传输。

## 三、使用注意事项

1. 请以**普通用户**身份、在**自有或已授权**的机器上运行本工具。
2. 报告中含主机名、用户名、端口、目录路径等本机信息，**请勿**提交至公开仓库（已 gitignore）。
3. 在隔离网络或敏感环境中运行时，建议使用 `--no-network`。
4. 探测结果仅反映"当前用户可访问"的情况，不构成完整的安全结论；请结合其他审计手段综合评估。
