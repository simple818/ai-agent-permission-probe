# 功能说明

## 一、项目定位

`ai-agent-permission-probe` 是一个**只读的 AI Agent 权限边界审计工具**，用于回答一个核心问题：**以当前用户身份运行的 AI Agent，在这台电脑上实际拥有哪些权限？** 探测结果以权限矩阵形式呈现，逐项标注状态、证据、风险等级与加固建议，供安全评审、最小权限整改与合规留痕使用。本项目与 `SKILL.md`（英文）、`SKILL.zh-CN.md`（中文）共同构成一个完整的、可被 Agent 加载使用的 Skill。

## 二、探测维度（8 大权限面，共 68 项检查）

| # | 权限面 | 检查内容 | 说明 |
|---|--------|----------|------|
| 1 | 身份与提权 | 当前用户、uid/gid、所属组、HOME/shell、sudo 状态、umask | `sudo` 仅以 `-n -l` 查询，绝不弹窗、不执行任何命令 |
| 2 | 文件系统 | 用户目录、系统目录、敏感目录、项目目录的读/写/执行权限；其他用户家目录可达性；真实可写性验证 | 识别 sticky 位（如 `/tmp`），避免误报 |
| 3 | Shell 与工具 | shell 执行能力、可用工具清单、PATH 卫生、homebrew | PATH 中用户可写/当前目录条目为高危篡改向量 |
| 4 | 网络 | 代理环境变量、DNS 解析、出站 TCP 连通性、本地监听端口、默认路由 | 出站检查仅为 TCP 连接尝试，不发送载荷 |
| 5 | 凭据 | 敏感环境变量**存在性**、凭据文件**存在性** | 只报存在与否与名称，**绝不读取内容** |
| 6 | 系统信息 | 平台、macOS 版本、CPU/内存、运行时长、磁盘、已装应用、进程可见性 | 用于评估资源与影响面 |
| 7 | GUI/浏览器（macOS） | 剪贴板可读性、浏览器配置文件存在性 | 浏览器配置可能含会话/凭据 |
| 8 | 安全基线（macOS） | SIP、Gatekeeper、FileVault 状态 | 关闭状态会显著扩大影响面 |

## 三、输出物

1. **`probe_report.json`**（结构化）
   - `meta`：工具版本、生成时间（UTC）、主机名、平台、用户、Python 版本、网络检查开关。
   - `risk_summary`：high / medium / low / info 计数。
   - `checks[]`：68 项检查，每项含 `category`、`check`、`status`、`evidence`、`risk`、`recommendation`。
   - `recommendations[]`：按发现聚合的加固建议清单。
   - `fixes[]`：8 条可选的修复项（含中英文标题、说明、修复命令、是否需要管理员权限）。

2. **`probe_report.md`**（人读）
   - 风险摘要表 → 权限矩阵表（68 行）→ 高/中风险发现 → 加固建议。

3. **`probe_report.html`**（可视化审计报告）
   - 深色终端风界面：meta 信息卡 → 风险摘要计数卡 → 可筛选/搜索的权限矩阵 → 高/中风险发现 → **修复中心**。
   - 界面中英文可切换，支持按风险等级筛选与关键字搜索。
   - **修复中心**：8 条加固项逐条给出修复命令，可〔复制命令〕手动执行，或〔交给 Agent 修复〕由 AI 自动处理；需管理员权限的项会标注"需管理员"。
   - **术语解释**：检查项后的 `?` 按钮点击展开"是什么 / 危害 / 加固"。

4. **`scripts/apply_fixes.py`**（可选修复脚本，与只读探测分离）
   - `--list`：列出全部修复项；`--fix <id>`：预览将执行的改动（默认不改任何东西）。
   - `--fix <id> --apply`：真正执行；修改配置文件前自动备份（`.bak.<时间戳>`）。
   - 需要管理员权限的操作在普通用户下不会执行，会提示改用 sudo。

## 四、命令行参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--output-dir DIR` | `./probe-report` | 报告输出目录（自动创建） |
| `--json` | 与 `--md`/`--html` 互选 | 仅输出 JSON |
| `--md` | 与 `--json`/`--html` 互选 | 仅输出 Markdown |
| `--html` | 与 `--json`/`--md` 互选 | 仅输出 HTML 可视化报告 |
| `--no-network` | 关闭 | 跳过出站 TCP 与 DNS 检查 |

## 五、风险分级标准

| 等级 | 判定示例 |
| --- | --- |
| high | 可写的非 sticky 系统目录、免密 sudo、PATH 含用户可写条目、SIP 关闭 |
| medium | 敏感目录可达、可读其他用户家目录、存在监听端口、敏感环境变量/凭据文件/浏览器配置存在、剪贴板可读、FileVault/Gatekeeper 关闭 |
| low | sticky 全局可写目录（如 `/tmp`）、PATH 干净、无 sudo 权限 |
| info | 身份、版本、资源数量等上下文信息 |

## 六、适用场景

- 部署 AI Agent 前的沙箱 / 最小权限边界评估；
- Agent 权限审计与整改（安全评审留痕）；
- 个人安全开源项目与 GTV 类背景提升的合规审计案例沉淀；
- 安全研究中的「Agent 爆炸半径」取证与基线建立。
