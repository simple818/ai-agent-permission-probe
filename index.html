AI Agent 权限边界探测（只读审计）

探测 AI Agent 在当前电脑上实际拥有的权限，输出带证据的权限矩阵与加固建议。信息安全开源持续贡献项目的一个迭代，聚焦 AI Agent 安全方向。

8 SURFACES · 68 CHECKS · READ-ONLY

风险分级标准

high 可写系统目录 · 免密 sudo · PATH 注入
medium 敏感目录可达 · 凭据存在 · 监听端口
low sticky 临时目录 · 干净的 PATH
info 身份与版本等上下文信息

FEATURES

功能特性

只读探测

不修改系统状态、不提权、不发送网络载荷，写入仅限报告目录与一枚即建即删的临时文件。

8 大权限面

身份与提权、文件系统、shell 与工具、网络、凭据、系统信息、GUI/浏览器、安全基线。

三格式报告

JSON 结构化（程序消费）+ Markdown 权限矩阵（人读）+ HTML 可视化报告（中英切换、可筛选搜索）。

真实可写性验证

临时文件实测而非仅看权限位，规避 TCC / ACL 下的误判。

风险分级与加固建议

每条发现带 high / medium / low / info 评级与对应处置建议。

零第三方依赖

仅用 Python 标准库，Python 3.9+ 即可运行。

PERMISSION SURFACES

探测维度（8 大权限面，共 68 项检查）

#权限面检查内容说明
01身份当前用户、uid/gid、所属组、HOME/shell、sudo 状态、umasksudo 仅以 -n -l 查询，绝不弹窗
02文件用户/系统/敏感/项目目录的读-写-执行权限，其他用户家目录，真实可写性验证识别 sticky 位（如 /tmp）避免误报
03Shellshell 执行能力、可用工具清单、PATH 卫生、homebrewPATH 用户可写/当前目录为高危
04网络代理环境变量、DNS、出站 TCP、本地监听端口、默认路由仅为 TCP 连接尝试，不发送载荷
05凭据敏感环境变量存在性、凭据文件存在性只报存在与否，绝不读取内容
06系统平台、macOS 版本、CPU/内存、运行时长、磁盘、已装应用、进程可见性用于评估资源与影响面
07GUI剪贴板可读性、浏览器配置文件存在性（Chrome/Safari/Firefox）浏览器配置可能含会话/凭据
08基线SIP、Gatekeeper、FileVault 状态关闭状态会显著扩大影响面

QUICK START

快速开始

进入项目

clone 或进入项目目录

cd ai-agent-permission-probe

直接运行

无需安装任何依赖

python3 scripts/probe_permissions.py --output-dir ./probe-report

查看报告

打开权限矩阵报告

open probe-report/probe_report.md

常用参数：--output-dir 指定输出目录 · --json/--md/--html 选择格式 · --no-network 跳过网络检查（隔离网络使用）。

OUTPUT

输出说明

probe_report.json

  • meta 环境与时间戳
  • risk_summary 风险计数
  • checks[] 68 项检查，含状态/证据/风险/建议
  • recommendations[] 加固建议清单
  • fixes[] 8 条可选修复项

probe_report.md

  • 风险摘要表
  • 权限矩阵表（68 行）
  • 高/中风险发现与证据
  • 加固建议

每次运行产出一份全新报告（含 UTC 时间戳），可按日期归档，便于整改前后对比与审计留痕。报告含本机主机名等本地信息，请勿提交公开仓库。

COMPLIANCE

合规与定位

  • 防御性安全。 仅做审计、检测、评估方向，无任何攻击、爆破、漏洞利用内容。
  • 只读审计。 不读秘密内容、不提权、不修改系统；输出仅用于权限评估与加固。
  • 单仓库双语。 一个项目，SKILL.md 英文可加载版 + SKILL.zh-CN.md 中文对照版。
